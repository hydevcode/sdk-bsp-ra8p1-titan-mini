# SDRAM 驱动示例

**中文** | [**English**](README.md)

## 简介

本示例展示如何在 **Titan Board Mini** 上使用 **RT-Thread 内存设备框架** 来实现 SDRAM 驱动功能。

主要功能包括：
- 初始化 RA8P1 SDRAM 控制器
- 内存配置和时序设置
- 集成 RT-Thread 内存管理

## SDRAM 简介

### 1. 概述

**SDRAM（同步动态随机存取存储器）** 是一种与系统时钟同步的易失性存储器，具有更快的访问速度。

### 2. RA8P1 SDRAM 特性

- **大容量**：最高支持 64MB 外部存储
- **高速**：支持高频运行
- **32位总线**：宽数据总线，高吞吐量

## 硬件说明

SDRAM 芯片连接至 MCU 的外部存储接口。具体请参考硬件手册。
